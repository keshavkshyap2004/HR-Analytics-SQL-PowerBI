# HR Analytics Dashboard | SQL & Power BI

## Project Overview
This project focuses on analyzing employee data to
understand workforce trends and employee attrition.

Using SQL and Power BI, I explored HR data to identify
attrition patterns across different departments,
job roles, salary levels, and employee demographics.

## Tools & Technologies
- SQL
- Power BI
- Data Analysis
- Data Visualization

## Project Objectives
- Analyze overall employee attrition.
- Understand attrition across departments.
- Identify job roles with high attrition.
- Analyze employee satisfaction.
- Explore the relationship between salary and attrition.
- Understand workforce distribution.

## SQL Analysis
I performed 30 SQL queries covering:

- Employee count and active employees
- Overall attrition rate
- Department-wise attrition
- Job role analysis
- Gender and age group analysis
- Salary slab analysis
- Overtime and job satisfaction
- Work-life balance
- Business travel analysis
- Advanced SQL using subqueries
- Window functions and ranking

## Power BI Dashboard
Created an interactive HR Analytics Dashboard
to visualize employee attrition and workforce trends.

## Key Areas of Analysis
- Employee Attrition
- Department Analysis
- Job Role Analysis
- Salary Analysis
- Employee Demographics
- Job Satisfaction
